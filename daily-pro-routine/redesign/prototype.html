Questions

When does a routine count?

When you really trained it. Sets can't be skipped, and the server checks that the real time has passed. In the Windows app, Fortnite or KovaaK's also has to run during the game sets.

Can the Windows app get me banned?

No. Repline never touches Fortnite: no memory, no game files, no network. It only looks at the list of running programs, like Task Manager or Discord does.

Do I need an account?

To train, yes: sign in with Discord, it's free. You can look at every routine without one.

Which keys can I use?

Space start or pause, R restart (+15 s while you switch), F full screen.
