Questions

How do I enter a Fortnite map code?
In Fortnite open Discover, press the search or Island Code button, paste the code and launch the island.
Which map is best to warm up in Fortnite?
A mechanics map like Raider464's V5 covers aim, edits and freebuild in one place. Follow it with a few real box fights.
How do I import a KovaaK's playlist?
In KovaaK's go to Playlists, choose Import and paste the share code.
